# 视觉基础升级 · 2.1

日期：2026-10-25。保留既有标准件、发动机目录、存档格式和连续飞行模型，重做车间、发射场、材质、近景细节、天空和光照。

## 本轮落实

| 系统 | 实现 |
|---|---|
| 材质 | 5 套本地 PBR 素材，分别使用颜色、法线、粗糙度贴图；喷漆、金属、橡胶、铜管有不同的反射性质 |
| 制造车间 | 门式钢架、墙板、吊车、维护平台、格栅、栏杆、梯子、管线、器材车、地面排水沟与工作区标线 |
| 接触关系 | 按火箭直径生成运输支撑架；修正阴影相机近远平面、投影矩阵与偏移，增加屏幕空间接触遮蔽 |
| 火箭近景 | 程序化喷管肋纹、内壁、泵体、供给管线、执行杆、紧固件和接缝细节；仍为近似外形，不是原厂 CAD |
| 发射设施 | 桁架塔、平台、栏杆、脐带、避雷杆、推进剂罐区、连接管线、围栏和附属建筑 |
| 地表 | 大范围曲面地形与近景地形分开；远景网格留出近景孔洞，减少两层网格相交；草地颜色采用多方向采样减轻重复 |
| 植被与海岸 | 树干、树冠叶片实例、岩石、海岸线、水面波动与随视角变化的反射；不再使用圆锥树 |
| 天空 | Rayleigh/Mie 单次散射积分、曲面大气边界、低分辨率体积云采样与缓存；天气密度同时影响近地材质直射光 |
| 室内外一致性 | 车间使用室内反射；室外使用天空反射；在轨降低环境反射并保留太阳与地球方向的近似补光 |
| 后处理 | 与对数深度匹配的接触 AO、低空高度雾、温和泛光和 FXAA |
| 检视操作 | 增加「发动机近景」「整箭视角」「纯场景」；H 可隐藏或恢复界面，画面检视不修改蓝图 |

## 测试记录

- 75 项核心/回归测试通过，飞行模型未为画面重做而更改。
- 12 项浏览器测试全量通过。阴影投影与发布分包调整后，另外复测连续入轨、离线版、近景检视和室外着色器 4 项通过；室内外模式复位修正后，再复测 2 项视觉场景检查。覆盖范围包括包括完整入轨、资源实际加载、检视相机、H 隐藏/恢复界面、室外着色器、地表与天空、离线入轨。
- 真实浏览器手动检查车间、发动机、发射场镜头，修复合批几何索引不一致、云层采样条纹、天空计算过慢、地形重叠和纹理重复等问题。
- 天空在较低分辨率计算并缓存，减少逐像素云采样开销。帧率依赖设备；截图内数字不是性能承诺。

## 当前边界

本轮建立的是更完整的视觉基础，不宣称与 Tidewater 的整体画质等价。阴影采用局部正交阴影图，非完整级联 PCSS；AO 为自定义屏幕空间近似；大气为单次散射，未实现多重散射 LUT。体积云主要用于天空，近地云影共享密度；云与前景地物的严格逐像素体积合成、时间重投影和时域超分仍未实现。海面为近似多尺度波动，非 FFT 海洋。

设施和树木是程序模型，地形是虚构发射场与近似曲面，不是全球摄影测量数据。材质更新不把未核实的发动机资料变成真实硬件保证。

生产构建另经独立浏览器检查：WebGL 2 初始化成功、全部材质加载完成、车间/发动机/发射场镜头无页面或控制台错误。
