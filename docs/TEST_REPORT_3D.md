# MERIDIAN 3D 开发验证报告

日期：2026-10-25（Asia/Shanghai）。

本页保留地球入轨基础版的验收记录；2.1 视觉更新增加到 12 项浏览器测试，另见 [VISUAL_UPGRADE.md](VISUAL_UPGRADE.md)。

## 已通过的检查

- TypeScript 严格类型检查与 Vite 生产构建。
- 75 项自动核心/回归测试：35 项新的三维制造、飞行、资料与存档测试；40 项旧二维核心回归。
- 10 项 Playwright 浏览器测试，包括真实 UI 的连续发射入轨和完全离线的单文件版入轨。
- 默认标准件构型达到目标轨道并完成无推力验证；继续传播时不停止世界。
- 重载 10 t 与低成本 2.5 t 任务各有独立三星解，经实际仿真而非仅静态估算验证。

## 三维核心覆盖

- 真实地球圆轨道的速度、周期、近远地点与偏心率。
- 无推力能量误差、时间步长分组一致性、地球自转初速与相对大气速度。
- 储箱几何/模块叠加、推进剂质量、材料、发动机并联对性能与成本的影响。
- 安装空间、燃料兼容、主阀、推重比、分离器与异径适配器约束。
- 分级前后速度与上面级燃料连续；整流罩按所选部件质量抛离。
- 不合适的转弯程序即使有较高理论 Δv 也会失败。
- 15 型真实发动机参考配置唯一标识、来源记录、未核实字段分离与英制换算。
- 仿真不修改蓝图；模拟不授予正式成绩；存档结构验证、刷新恢复与旧存档隔离。
- 首飞、重载和经济方案的实际轨道验收。

## 环境与边界

macOS、Node.js 26.8.2、Chrome / WebGL 2、Playwright。主要桌面视口 1440×1000，窄屏 390×844。没有完成 Safari、Firefox、真实移动设备、低端 GPU 或长时间外部玩家测试。

本报告验证功能与模型数值性质，不证明真实发动机工程精度。资料中的未知字段、估计控制包线、游戏安装标准与简化热/结构/姿态模型均在游戏和文档中明确区分。
